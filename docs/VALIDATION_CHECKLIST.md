# Website Validation Checklist

## Objetivo
Validar rapidamente se o Website está pronto para apoiar operação real e venda inicial.

## Checklist
- homepage abre sem erros
- teaser em destaque aparece quando existe
- links para `novidades`, `em-breve`, `loja` e `ips` respondem
- produto ativo abre página correta
- CTA principal empurra para descoberta ou compra
- copy de confiança e conversão continua visível

## Regra prática
O Website deve refletir o que o Studio mandou publicar. Se o estado público estiver errado, corrigir primeiro no Studio.

## Meta
Menos tempo a adivinhar. Mais tempo a validar o funil real de descoberta e compra.
