# Website vs External Channels

## Objetivo
Evitar confusão entre o papel do Website próprio e o papel dos canais externos.

## Website próprio
Serve para:
- descoberta
- pré-lançamento
- venda direta
- primeiras receitas

## Canais externos
Servem para:
- escalar alcance
- abrir novos pontos de entrada
- multiplicar distribuição

## Regra
O Website continua a ser o primeiro canal próprio. Os canais externos entram depois, controlados pelo Studio.

## Meta prática
Primeiro provar o funil no Website. Depois escalar para Amazon, YouTube e outros destinos.
