# Website Monetization Role

## Objetivo
Fixar o Website como o primeiro canal de monetização real.

## Papel do Website nesta fase
- receber publicação vinda do Studio
- gerar descoberta
- empurrar para compra
- validar o funil base de receita

## Regra
Antes de escalar para canais externos, o Website próprio deve provar que consegue transformar uma produção boa em venda real.
