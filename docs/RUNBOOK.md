# Website Runbook

## Papel
O Website é o canal próprio de descoberta, pré-lançamento e venda direta.

## Ordem prática
1. o Studio define o estado público
2. o Website reflete esse estado
3. a homepage destaca o melhor teaser ativo
4. a loja fecha a compra

## Regra
O Website recebe publicação. Não comanda a distribuição multicanal.
