# Website Release Flow

## Objetivo
Ter uma sequência curta e clara para passar de alteração aprovada a validação pública.

## Fluxo
1. o Studio prepara teaser, estado público e assets
2. o Studio publica para Website
3. validar homepage
4. validar teaser em destaque
5. validar páginas de descoberta e loja
6. só depois considerar distribuição externa

## Regra
Se o Website mostrar algo errado, corrigir primeiro no Studio. O Website reflete publicação, não manda na publicação.

## Meta
Menos confusão operacional e mais foco no funil real de descoberta e compra.
