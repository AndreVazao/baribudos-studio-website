# First Revenue Checklist

## Objetivo
Validar que o Website está pronto para suportar as primeiras vendas reais.

## Checklist
- homepage abre bem
- teaser em destaque faz sentido
- links principais funcionam
- página de produto abre sem falhas
- CTA empurra para descoberta ou compra
- fluxo Studio para Website está coerente

## Regra
Se o Website não estiver a refletir corretamente o que foi decidido no Studio, corrigir primeiro no Studio.
