# Website in V4

## Objetivo
Fixar o papel do Website quando a fase de integrações externas reais começar.

## O Website continua a ser
- o primeiro canal próprio
- o primeiro canal de monetização
- o primeiro ambiente para provar o funil

## O Website não deve virar
- painel de integração externa
- centro de distribuição
- substituto do Distribution Hub

## Regra
Na v4, mesmo com Amazon e YouTube a avançarem, o Website continua a receber publicação vinda do Studio e a funcionar como canal próprio principal.
