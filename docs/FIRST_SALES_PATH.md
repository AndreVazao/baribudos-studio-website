# First Sales Path

## Objetivo
Fixar o caminho mais curto para transformar uma produção boa em venda real usando primeiro o Website próprio.

## Sequência
1. produzir no Studio
2. fechar teaser, cover, CTA e estado público
3. publicar para Website
4. validar homepage e páginas públicas
5. empurrar para loja
6. observar primeiras vendas

## Regra
Antes de escalar para canais externos, o Website próprio deve provar o fluxo base de descoberta e compra.
