==================================================
ARCHITECTURAL READING OF THIS TREE
==================================================
- Website is a public Next.js application.
- Public rendering lives in src/app.
- Admin rendering lives in src/app/admin.
- Private import endpoint already exists under src/app/api/admin/import-package/route.ts.
- Persistence layer is Prisma/PostgreSQL.
- Catalog projection lives in the Prisma models and sync-commerce logic.
- Website is already structured to act as the public/commercial consumer of Studio-origin publications.

==================================================
TREE GOVERNANCE RULE
==================================================
Before structural refactors:
1. Keep this repository separate from Studio.
2. Introduce official Studio intake before removing manual admin import fallback.
3. Preserve public pages and green builds.
4. Extend data model and ingest contract in small reversible steps.
5. Keep Website as public/commercial projection, never source-of-truth editorial core.
